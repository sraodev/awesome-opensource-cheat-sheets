# Security Policy

This repository contains documentation links and downloadable reference files rather than executable software. Relevant security concerns include a linked resource becoming malicious, a committed file being replaced or compromised, or credentials appearing in repository content or automation.

## Reporting a concern

Do not open a public issue for a concern that could put users at risk. Email [srao.dev@gmail.com](mailto:srao.dev@gmail.com) with:

- the affected URL or file;
- what you observed and when;
- steps to reproduce or verify it;
- any evidence that can be shared safely.

For an ordinary broken, redirected, or outdated link, use the [link report form](https://github.com/sraodev/awesome-opensource-cheat-sheets/issues/new?template=broken-link.md).

The maintainer will acknowledge security reports as soon as practical, investigate the affected resource, and remove or replace unsafe content when confirmed.
